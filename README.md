# さくせんAI バトルラボ

最大3対3のターン制AI戦闘シミュレーターです。職業、敵、敵グループ、技、作戦、AI評価パラメータをブラウザ上のエディターから変更できます。

## 起動方法

Windowsでは `start.bat` をダブルクリックしてください。ローカルサーバーとブラウザが起動します。終了時は「DQ4demo Server」ウィンドウを閉じてください。

標準データをJSONから読み込むため、`index.html`を直接開かず、`start.bat`、VS Codeのローカルサーバー、またはGitHub Pagesから起動してください。ビルドやパッケージのインストールは不要です。

## 戦闘操作

- 「STEP 1人」：素早さ順に1人だけ行動します。
- 「1ターン実行」：現在のターンの残りを実行します。
- 「自動戦闘」：勝敗が決まるまで自動進行します。
- 「敵グループ」：登録済みの編成を選ぶと、その編成で新しい戦闘を開始します。
- 戦闘終了後の「ログを見る」：結果表示だけを閉じ、戦闘状態とログを残します。
- 味方カード：直近のAI判断を表示します。
- 候補ランキング：候補を選ぶと評価内訳を表示します。

## データエディター

戦闘画面右上の「データ編集」から開きます。

初回起動時は`data/default-game-data.json`を読み込みます。ブラウザに保存済みデータがある場合はlocalStorageの`dq-ai-battle-data-v1`を優先するため、既存の編集内容は失われません。「GitHub標準値を読込」を選ぶと最新の標準JSONを再取得しますが、「保存」するまではlocalStorageを書き換えません。

- 職業：Lv別ステータス、参加状態、使用技と習得Lvを編集できます。
- 敵：固定のHP、MP、攻撃力、守備力、素早さ、使用技、属性耐性を編集できます。敵自身はLv別成長しません。
- 敵グループ：1～3体の編成を登録できます。同じ敵を複数枠へ指定することもできます。
- Lv別ステータス・習得Lv：職業ごとにLv1～24の成長値と、各技を何LvからAI候補へ加えるか設定できます。
- 職業適性：攻撃・守備・素早さ強化の適性と、回復・攻撃魔法の優先度を編集できます。
- 技・魔法：AI評価タイプ、対象、MP、基本評価と、実行する効果を編集できます。
- 効果一覧にはダメージ、HP回復、能力変化、即死、反動、状態異常付与、状態異常治療、蘇生を複数登録でき、上から順に実行されます。
- 物理スキル：通常攻撃系のまま、物理攻撃倍率、属性、消費MPを設定できます。
- 補助魔法：強化する能力、加算・倍率、効果量、持続ターン、重ね掛け上限を編集できます。
- 技の編集画面から、その技を使う職業・敵へ直接割り当てできます。
- 作戦：行動タイプごとの評価倍率を編集できます。
- AI設定：HPしきい値、各種加減点、ランダム幅などを編集できます。
- 行動順：ターン開始時は行動を決めず、毎ターン「素早さ×0.75～1.25」の乱数値で順番だけを決めます。各キャラクターは自分の行動直前に最新の戦況から行動と対象を判断します。最小・最大倍率はAI設定で変更できます。
- 「新規」「複製」「削除」でデータを増減できます。
- JSON出力・読込により設定を共有、バックアップできます。
- 「この項目を保存」は現在の項目だけを保存し、戦闘をリセットしません。技・使用者・作戦・AI設定は進行中の戦闘にも反映されます。
- 「保存して戦闘へ反映」は編集内容全体を保存し、基本ステータスを含めて戦闘をリセットします。

標準データにはスクルトに加えてバイキルトが登録されています。新しい強化魔法は、行動タイプを「補助」にして効果の能力と計算方式を設定してください。行動タイプ自体はAI評価方法に対応する固定分類です。

毒はターン終了時に最大HPの設定割合だけダメージを与え、幻惑は物理攻撃の命中率を下げ、石化は行動不能にします。標準データには毒攻撃、石化攻撃、マヌーサ、キアリー、ザオリクを登録しています。キアリーは毒を治療し、ザオリクは戦闘不能者を最大HPで蘇生します。

標準データには戦士用の「炎斬り」も登録されています。物理スキルは行動タイプを「通常攻撃」にし、物理攻撃倍率を1より大きくして属性を指定します。物理ダメージは、攻撃力と守備力から求めた値へ最後に敵の属性耐性倍率を掛けます。

技を使用中の職業や敵が存在する場合、その技は削除できません。敵グループで使用中の敵も削除できません。戦闘に参加できる味方と敵は現在それぞれ3体までです。

職業の編集画面では「＋ Lv追加」「このLvを複製」「Lv削除」を使用できます。「戦闘で使用するLv」で選んだ能力値は、次に開始する戦闘から適用されます。敵は1種類につき1組の固定ステータスです。

「技と習得Lv」では、技のチェックと習得Lvを同時に編集できます。現在Lvが習得Lv未満の技は、そのキャラクターのAI候補に表示されません。標準データはHD-2D版DQ3の職業傾向と主な習得時期を参考にしたシミュレーター用調整値で、性格・装備・ランダム成長まで含むゲーム本編の実測値そのものではありません。

## ソース構成

- `data/default-game-data.json`：職業、敵、技、敵グループなどの標準ゲームデータ
- `js/default-data.js`：標準JSONの取得と初期化
- `js/action-schema.js`：旧形式の技項目と`effects`形式の変換・同期
- `js/data-store.js`：保存、読込、検証、参照確認
- `js/models.js`：キャラクター、敵知識、ログ
- `js/battle-events.js`：行動前、効果前後、行動後、ターン終了などのイベント通知
- `js/status-engine.js`：毒・幻惑・石化の保持とターン処理
- `js/target-resolver.js`：行動対象の条件解決
- `js/effect-engine.js`：効果ごとの予測計算と状態変更
- `js/action-executor.js`：複数効果の実行と戦闘ログ生成
- `js/battle-ai.js`：候補生成と評価関数
- `js/battle.js`：ターン進行と各機能の連携
- `js/battle-ui.js`：戦闘画面の描画と操作
- `js/editor-ui.js`：データエディター
- `js/main.js`：各機能の初期化

## HD-2D版DQ3データ

- 標準データはHD-2D版『ドラゴンクエストIII そして伝説へ…』を基準にしています。
- 戦士・僧侶・魔法使い・勇者・賢者にLv1～50の標準成長値と習得Lvを登録しています。習得Lvは賢さで前後するため最短Lvです。
- 性格・種・転職・装備で能力値が変わる本編とは異なり、Lv別能力値はAI比較用の決定論的な標準成長曲線です。
- モシャス、パルプンテ、かばうなど、現在のエンジンで正確に再現できない行動もデータには残し、戦闘候補外として表示します。
- 魔物はHD-2D版の内部Lv・HP・MP・攻撃・守備・素早さを参考に、Lv50まで53種類、敵グループ31種類を登録しています。
- `node scripts/build-hd2d-data.mjs` で標準JSONを再生成できます。
